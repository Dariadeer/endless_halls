## Project role descriptions
### Management
#### PM
- Meeting organisation
- Communication with the sponsor(s)
- Defining requirements and issuing corresponding tasks to developers
#### Deputy PM
- Taking on the role of PM if they are not available
---
### Development
#### Backend developer
- Completion of tasks assigned by PM regarding the server side of the project
- Responsibility for the business logic and data access layers
#### Frontend developer
- Completion of tasks assigned by PM regarding the client (browser) side of the project
- Responsibility for the user interface layer (both design and implementation)
#### DevOps 
- Completion of tasks assigned by PM regarding the repository and production sides of the project
- Responsibility for setting up the production server and its environment, database
- Managing proper access rights to the git repository
- Code deployment for demo/production
---
### Others
#### Documenter
- Description of all user -> client -> server interactions
- Description of the project structure, tools and setup procedures
#### Editor
- Validation of the work of one or multiple documenters
#### Tester
- Composition of unit/integration tests
- Design of user acceptance tests
---

## Project idea
*Note: The project ideas seem to be barely coherent with each other, might be more suitable to develop them into multiple loosely-connected web applications (micro-service architecture?).*

1. Volunteer matching (6)
	- A bounty-based social platform where users can post requests for help and other users can accept. 
	- A recommendation page to show users bounties closer to their geolocation.
2. Navigating the first job (1)
	- A budgeting app to decently approximate daily/weekly/monthly expenses.
	- Various calculations to predict pension and savings values.
	- Guides explaining the above-mentioned calculations and generally useful info regarding pay checks and long-term concepts.
3. Cybersecurity (10) (the most incoherent topic with others)
	- A guide app explaining dangers of common scams.
	- Practical examples that simulate the situations.
	- A deeper insight into the schemes (optional for the user)
4. All
	- Gamification can be applied to each of the topics individually (possibly united under one user system?)
	- Volunteering
		- Social impact -> unlocking new levels and distinctions.
		- Seasonal leaderboards.
		- Groups (aka guilds or clans)?
	- Job + Cyber (2 and 3)
		- Interactive information presentation.
		- A campaign (mini-course) covering all topics throughout its levels.
